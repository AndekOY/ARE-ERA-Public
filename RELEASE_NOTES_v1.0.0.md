# ARE / ERA Public v1.0.0 — Release Notes

**Release date:** 2026-10-21
**Release type:** First public documentation and synthetic methodology demonstration
**Repository:** https://github.com/AndekOY/ARE-ERA-Public

## Overview
The first public release introduces **ARE (ANDEKS Runtime Engine)** and **ERA (Evidence Review and Assessment)**, an applied evidence-assessment system built on ARE. It provides selected public architecture and evidence-model documentation and a synthetic example illustrating how claims, available evidence, verification gaps and bounded results can be distinguished.

## Included
- ARE/ERA architecture overview and system boundaries.
- ARE and ERA public descriptions.
- Evidence model vocabulary.
- Synthetic Demonstrator 01: Evidence Integrity and Provenance Claims.
- Synthetic claim matrix, fictional source register, assessment rationale and limitations.
- Rights notice (all rights reserved).

## Important boundaries
- This release **does not** contain ARE or ERA source code, a runnable software distribution, an independently validated software benchmark or evidence of a real software execution.
- Demonstrator 01 is **synthetic**. It does not evaluate, identify, endorse or make findings about any real company or product.
- **UNESTABLISHED** in the example means that the fictional evidence bundle is insufficient for independent verification. It does not mean an implementation defect has been proven.
- **ANDEKS™** is a separate normative assessment system. This release contains no ANDEKS™ normative finding, certification or standing determination.
- All rights reserved. No open-source license is granted.
