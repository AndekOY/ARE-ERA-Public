# Demonstrator 01: Evidence Integrity and Provenance Claims

**SYNTHETIC CASE / METHODOLOGICAL ILLUSTRATION / NOT A VENDOR AUDIT**

A fictional provider, **Example Signal Service**, claims to create tamper-evident daily digests and maintain source-to-signal provenance. The fictional evidence bundle includes a descriptive methodology and one sample signal metadata record, but omits the original source artifact, complete transformation log, actual digest-bearing snapshot bytes and an independently verifiable chain anchor.

The assessment question is: *Does this illustrative evidence bundle establish end-to-end integrity and provenance?*

**Illustrative result: UNESTABLISHED.** A method description and metadata fields do not themselves establish an independently reproducible integrity chain. The result is **not** evidence that the fictional provider's internal system is defective. No real provider is identified, assessed, endorsed or implicated.

This case is **inspired by a general class of public evidence-integrity questions**, not a reproduction of any company's records. Names, records and artifacts are synthetic. It is a reasoning demonstration, **not a recorded execution of ARE/ERA** and **not an ANDEKS™ normative finding**.
