# ERA: Public overview

ERA stands for **Evidence Review and Assessment**. It is an applied evidence-assessment system built on ARE. The documented assessment logic separates: (1) the claim being assessed; (2) evidence available for inspection; (3) checks that can be reproduced; (4) missing evidence or controls; (5) the narrowest supported outcome.

A bounded result such as **UNESTABLISHED** indicates that the examined evidence does not support a stronger determination within the stated scope. It is not a negative judgment about the internal implementation of an unidentified system.

The synthetic demonstration illustrates this reasoning, not a verified run of the ERA software.
